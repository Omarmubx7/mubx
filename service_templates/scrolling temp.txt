Follow these rules strictly:

1. Do NOT make it look like a normal landing page.
2. Do NOT use a generic hero + cards + testimonials + FAQ layout.
3. Do NOT make it feel like a cheap blog, fan-made template, or startup site.
4. Do NOT use loud, random effects that reduce elegance.
5. Do NOT overuse shiny gradients, floating blobs, or fake futuristic design.
6. Do NOT use repetitive card sections with identical layouts.

# Storytelling Structure
Build the site as a scroll-driven narrative with one section revealed at a time.

Each section should feel like a scene or chapter in a film.

Suggested story arc:
1. Opening cinematic intro
2. Origins / early beginnings
3. Formation / identity taking shape
4. Place / environment / iconic setting
5. Struggle / tragedy / challenge / tension
6. Breakthrough / success / defining era
7. Key figures / symbols / cultural identity
8. Global reach / influence / legacy
9. Final emotional closing section

Do not make these sections feel like basic content blocks.
Each one should have its own mood, pacing, composition, and transition style.

# Scroll Experience Rules
The scroll behavior is one of the most important parts of this website.

Requirements:
- The site should reveal one chapter at a time
- Each section should have a strong entry and exit
- Scrolling should feel smooth, dramatic, and premium
- The experience should guide the user through the story with deliberate pacing
- Transitions must feel cinematic, not gimmicky
- Use depth, layering, parallax, scale, masking, pinned sections, and motion sequencing where appropriate
- The user should feel movement through time, memory, and space

Important:
- The scroll effects must feel expensive and polished
- The motion must support storytelling, not distract from it
- Avoid cheap scroll-jacking
- Avoid performance-heavy effects that feel messy or laggy
- Respect reduced motion preferences

# 3D Direction
The site should include great 3D or pseudo-3D storytelling moments, but in a tasteful premium way.

Possible examples:
- layered depth transitions
- environmental world-building
- floating archival elements in 3D space
- symbolic objects revealed through motion
- dramatic camera-style movement between story chapters
- perspective-based scene compositions
- lighting-driven visual depth
- subtle volumetric atmosphere
- parallax scene construction with premium realism

If true 3D is used, it must be elegant, smooth, and meaningful.
If pseudo-3D achieves a more premium result, prefer that over forced WebGL.

Never add 3D just for the sake of saying the site has 3D.
The effect must elevate the story.

# Technical Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Components**: Shadcn/ui only when needed, not to make it look templated
- **Animation**: Framer Motion and/or GSAP if necessary
- **3D**: Use React Three Fiber only if it clearly improves the experience
- **Icons**: Lucide React only when genuinely useful
- **Images**: highly optimized
- **Fonts**: use `next/font`
- **Performance**: production-grade optimization required

# Motion Rules
Motion must feel premium:
- smooth
- restrained
- cinematic
- layered
- immersive
- intentional

Avoid:
- bouncy startup animations
- cheap zoom spam
- excessive blur spam
- random floating objects
- animation on every element
- generic fade-up on everything

Instead:
- build choreographed motion systems
- create section-by-section transitions
- use scale, opacity, masking, pinning, stagger, depth, and perspective with restraint
- make the motion feel authored

# Section-by-Section Build Requirement
Do not try to generate the whole website carelessly in one pass.

Work in this order:
1. Define the creative direction and storytelling system
2. Define the visual design system
3. Define the scroll and motion system
4. Scaffold the page structure
5. Build each story section intentionally, one section at a time
6. Ensure all sections connect smoothly as one narrative experience
7. Polish transitions, responsiveness, and performance
